<h2 align="center">Research summary</h2>

<p>This study examines dementia-related crash severity prediction using 4,781 Texas crash records from 2017–2025, combining structured variables with police narratives. The framework controls outcome leakage, calibrates prediction confidence, and defers uncertain cases to human review. It evaluates severity-aware decision rules with particular attention to under-triage of fatal and severe-injury crashes, while preserving predictions and model outputs for audit. Dementia status is reported in crash records and is not a clinically verified diagnosis.</p>

<p><strong>Keywords:</strong> Crash severity; dementia; outcome leakage; probability calibration; selective deferral; human review.</p>
